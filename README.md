# Навчання для вчителів · Математика та Інформатика

Короткі онлайн-заняття (30 хв) для вчителів НУШ про оцінювання за групами результатів та використання ШІ (Gemini) на уроках.

**Демо:** `https://<username>.github.io/<repo-name>/`

## Структура

```
/
├── index.html          ← стартова сторінка (хаб)
├── matematyka.html     ← заняття: 3 групи результатів + Gemini
└── informatyka.html    ← заглушка (у розробці)
```

## Що всередині сторінки заняття

- **Старт-екран** із кнопкою «Давайте вчитися» — натискаєш, починається відлік
- **Таймер на 30 хвилин** — після старту згортається в кут, залишається видимим між слайдами
- **10 повноекранних слайдів** із плавною анімацією переходів
- **Прогрес-бар угорі** — показує, скільки контенту попереду
- **Чорно-біла трансформація** усього сайту, коли таймер завершується
- **Промпти для Gemini** із кнопкою «копіювати»

## Навігація на сторінці заняття

- `↑` `↓` або скрол — між слайдами
- `Space` — наступний
- Свайп — на мобільному
- Точки навігації справа — швидкий перехід

## Розгортання на GitHub Pages

1. Створити публічний репозиторій
2. Завантажити всі три HTML-файли в корінь
3. Settings → Pages → Source: `main`, папка `/ (root)` → Save
4. Через ~хвилину сайт буде доступний за посиланням
